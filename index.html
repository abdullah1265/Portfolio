About

I'm Muhammad Abdullah, a BSCS graduate with a focus on front-end web development. I enjoy the moment a static design becomes a living interface — where a layout responds to a screen, a button reacts to a click, and a page feels considered rather than assembled.

My work centers on HTML, CSS, and JavaScript, with an emphasis on responsive layouts, clean component structure, and interfaces that hold up on any device. I care as much about how the code is organized as how the final page looks.

Currently building projects, sharpening fundamentals, and looking for opportunities to contribute to real-world products as a front-end developer.
